# Vault Of Specs

Open product database: brands, products and their specs, with links to the pages the specs came from. Under construction ⚠️

Site: https://karpuzikov.github.io/vault-of-specs/

Data is read from the [OLX Model Tags](https://github.com/karpuzikov/userscripts/tree/main/browser-tools/olx-model-tags) catalog (`olx-model-tags-catalog.json`, `olx-model-tags-rawspecs.json`); the userscript captures specs from official brand sites and writes them there. This site only reads.
